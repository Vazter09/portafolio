# Portafolio — Desarrollador Fullstack Freelance

Sitio personal estático (HTML, CSS y JavaScript sin dependencias).

**Ver en vivo:** https://vazter09.github.io/portafolio/

## Personalizar

1. Edita el bloque `CONFIG` en `script.js` (nombre, rol, correo, redes).
2. Coloca tu foto en `img/perfil.jpg`.
3. Actualiza servicios, proyectos y stack directamente en `index.html`.

## Estructura

```
index.html   Contenido y secciones
styles.css   Estilos (paleta y componentes)
script.js    Configuración personal y lógica de la caja de perfil
img/         Imágenes del sitio
```
